# 証券口座えらび診断（securities-account-finder）

7つの質問に答えるだけで、自分に合うネット証券がわかる診断ツールです。
SBI証券・楽天証券・マネックス証券・松井証券・三菱UFJ eスマート証券・moomoo証券・PayPay証券・大和コネクト証券の8社を、回答に応じて採点し、TOP3を理由付きで表示します。

## 特徴
- HTMLファイル1つで動作（サーバー・API キー・インストール不要）
- スマホ対応、結果の印刷／PDF保存
- 「担当者に相談したい」人には総合証券の案内を表示し、初心者には サポート重視で採点
- 8社の比較表（手数料・ポイント・クレカ積立・1株投資・IPO・アプリ・サポート）を同梱
- 比較データは `index.html` 冒頭の `BROKERS` 配列にまとまっており、更新しやすい構造

## 使い方
`index.html` をブラウザで開くだけです。

## 動かすのに必要なもの
なし（モダンブラウザのみ）

## データについて
比較データは 2026年9月時点の公開情報をもとにしています（出典は `データ出典（NotebookLM調査 2026-09）.md` を参照）。
条件は変更されることがあるため、最新の内容は各社公式サイトでご確認ください。
